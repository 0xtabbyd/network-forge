# network-forge

> ⚠️ Work in progress — 開発中です

ブラウザで動くネットワーク構成図作成ツール。物理構成図を一度作れば、論理・ハイブリッド・VLANビューが自動生成されます。

## 作った背景

前職のインフラ現場では、ネットワーク構成図の作成ルールが標準化されておらず、以下のような課題があった。

- **二度手間**：物理配置図と論理構成図をそれぞれ別々に作成する必要がある
- **ツールの分散**：PowerPointやExcelで管理されており、更新が属人化している
- **陳腐化**：顧客が機器を追加しても構成図が更新されないまま放置される
- **導入ハードル**：Draw\.ioを試みたが、VSCodeに不慣れなメンバーには定着しなかった

**「物理構成図を一度作れば、論理構成図やハイブリッドビューも自動で出てくるツールが欲しい」** という課題からこのツールを開発した。

インストール不要、ブラウザだけで動くことを重視している。

---

## 主な機能

### 複数ビューの自動生成
物理構成図を作成すると、以下のビューが自動で切り替え可能になる。

| ビュー | 内容 |
|--------|------|
| 物理 | 機器の実際の接続構成 |
| 論理 | L3レベルのネットワーク構成 |
| ハイブリッド | 物理と論理を重ねた表示 |
| VLAN | VLANセグメントの可視化 |
| ポート | 各機器のポート接続状況 |
| IPリスト | インターフェースとIPアドレスの一覧 |
| ケーブル | ケーブル配線の一覧 |

### ドラッグ＆ドロップで機器を配置
パレットからルーター・スイッチ・サーバー・ファイアウォールなどをキャンバスにドラッグするだけで配置できる。

### パケットシミュレーション
送信元と宛先を指定すると、パケットの経路をアニメーションで可視化する。ルーティングテーブルとデフォルトゲートウェイに基づいた経路計算を行う。

### ネットワーク検証
IPアドレスの重複・未設定、ゲートウェイの疎通確認などを自動でバリデーションし、警告を表示する。

### その他
- ダークモード / ライトモード対応
- ズーム・自動整列
- JSON形式でのプロジェクト保存・読み込み
- インストール不要（ブラウザのみで動作）

---

## 使い方

1. `network_designer.html` をブラウザで開く
2. 左パレットから機器をキャンバスにドラッグ＆ドロップ
3. 機器同士をクリックして接続
4. 右パネルでIPアドレス・インターフェース・ルーティングを設定
5. 上部タブでビューを切り替え

---

## 動作環境

インストール不要。モダンブラウザ（Chrome / Firefox / Edge）で動作する。
